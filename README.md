## 📖 Research Details

### ❓ Research Problem
The IT recruitment process faces significant inefficiencies affecting both job seekers and recruiters.

**Challenges for Job Seekers:**
- Difficulty finding roles tailored to skills due to generic CVs  
- Lack of centralized platforms connecting to suitable opportunities  
- Delayed feedback causing frustration and missed chances  

**Challenges for Recruiters:**
- Time-consuming manual CV screening leading to inefficiencies  
- Inability to accurately assess technical proficiency  
- Limited use of AI tools for streamlined candidate shortlisting  

### 🎯 Objectives
**Main Objective:**  
Develop a Computational Framework for Optimized Recruitment via Algorithmic Skill Profiling to enhance the efficiency and accuracy of IT hiring processes.

**Specific Objectives:**
- Design and implement a Resume Analyzer for candidate profile matching  
- Develop Skill-Based Assessments with gamified quizzes and leaderboards  
- Incorporate Video Analysis Technology for communication assessment  
- Automate Job Matching Algorithms using AI for real-time recommendations  

## 🚀 Getting Started

### Prerequisites
- Node.js 18.0 or higher  
- npm or yarn package manager

### Installation Steps
```bash
git clone https://github.com/Avishka777/TALENT-TREK-WEBSITE
cd TALENT-TREK-WEBSITE
npm install
npm run dev
```
Navigate to [http://localhost:3000](http://localhost:3000)

### Available Scripts
```bash
npm run dev     # Development server
npm run build   # Production build
npm start       # Start production server
npm run lint    # Lint code
```
